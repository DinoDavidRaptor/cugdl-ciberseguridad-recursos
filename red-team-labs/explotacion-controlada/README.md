# Explotación Controlada

Recursos sobre técnicas de explotación en entornos de práctica autorizados.

---

## ADVERTENCIA DE USO EDUCATIVO

Este contenido es exclusivamente para fines educativos y de investigación en ciberseguridad. Todas las técnicas descritas deben ser practicadas únicamente en entornos controlados y con autorización explícita. El uso no autorizado de estas técnicas en sistemas reales es ILEGAL y puede resultar en consecuencias legales graves.

---

## Temas

### Vulnerabilidades Web (OWASP Top 10)
- Inyección SQL
- XSS (Cross-Site Scripting)
- CSRF (Cross-Site Request Forgery)
- Deserialización insegura
- Configuraciones incorrectas
- Control de acceso roto

### Metasploit Framework
- Uso ético de Metasploit
- Módulos de explotación
- Payloads y encoders
- Meterpreter
- Post-explotación con Metasploit

### Explotación de Servicios
- Buffer overflow (en laboratorios)
- Explotación de servicios mal configurados
- Escalada de privilegios Linux
- Escalada de privilegios Windows
- Bypasses de autenticación

### Herramientas
- Metasploit Framework
- Burp Suite
- SQLmap
- ExploitDB
- SearchSploit

## Enfoque Defensivo

Cada técnica ofensiva debe incluir:
- Cómo detectar el ataque
- Cómo prevenir la vulnerabilidad
- Cómo mitigar el riesgo
- Controles de seguridad aplicables
