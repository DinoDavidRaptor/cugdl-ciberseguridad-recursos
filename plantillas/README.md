# Plantillas

Esta carpeta contiene plantillas estandarizadas para facilitar la creación de contenido consistente en el repositorio.

---

## Plantillas Disponibles

### plantilla-apuntes.md
Plantilla para crear apuntes teóricos sobre conceptos de ciberseguridad.

**Uso:**
- Apuntes de fundamentos
- Resúmenes de conceptos
- Guías de estudio
- Material teórico

### plantilla-laboratorio.md
Plantilla para documentar configuraciones de laboratorios y entornos de práctica.

**Uso:**
- Configuración de máquinas virtuales
- Setup de entornos de prueba
- Guías de instalación
- Laboratorios paso a paso

### plantilla-writeup.md
Plantilla para writeups de CTFs y desafíos de seguridad.

**Uso:**
- Soluciones de CTFs
- Writeups de HackTheBox/TryHackMe
- Resolución de desafíos
- Documentación de metodología

---

## Cómo Usar las Plantillas

1. **Copia la plantilla** correspondiente al tipo de contenido que vas a crear
2. **Renombra el archivo** con un nombre descriptivo
3. **Completa las secciones** siguiendo la estructura de la plantilla
4. **Elimina las secciones** que no apliquen a tu contenido
5. **Guarda el archivo** en la carpeta correspondiente del repositorio

---

## Beneficios de Usar Plantillas

- **Consistencia**: Todo el contenido sigue una estructura similar
- **Completitud**: No olvidar secciones importantes
- **Profesionalismo**: Presentación organizada y clara
- **Facilidad de lectura**: Los usuarios saben qué esperar

---

## Personalización

Las plantillas son guías, no reglas estrictas. Puedes:
- Agregar secciones adicionales relevantes
- Eliminar secciones que no apliquen
- Adaptar el formato a necesidades específicas
- Mantener la estructura general para consistencia

---

## Contribuir con Nuevas Plantillas

Si identificas la necesidad de una nueva plantilla:

1. Crea la plantilla siguiendo el formato de las existentes
2. Documenta claramente su propósito y uso
3. Actualiza este README con la nueva plantilla
4. Envía un Pull Request siguiendo [CONTRIBUTING.md](../CONTRIBUTING.md)
