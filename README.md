## Propósito

Este repositorio tiene como objetivo centralizar apuntes, resúmenes, laboratorios, herramientas y buenas prácticas relacionadas con la ciberseguridad, enfocándose en:

- **Blue Team**: Defensa, análisis forense, hardening, SIEM, respuesta a incidentes.
- **Red Team (Laboratorios Controlados)**: Pruebas de penetración en entornos de laboratorio éticos y legales.
- **Fundamentos**: Redes, sistemas operativos, criptografía, programación aplicada a seguridad.
- **Laboratorios**: Configuración de entornos virtualizados, CTF, writeups educativos.
- **Herramientas**: Guías de uso responsable de herramientas de seguridad para Linux, Windows y multiplataforma.

Este es un proyecto **educativo, ético y legal**, donde la colaboración y el respeto son fundamentales.

## Para Quién es Este Repositorio

Este repositorio está dirigido principalmente a:

- Estudiantes de ciberseguridad de la **Universidad de Guadalajara (CUGDL)**.
- Cualquier persona interesada en aprender ciberseguridad de forma responsable y ética.
- Profesionales que deseen compartir conocimientos con la comunidad educativa.
- Participantes de CTFs y competencias de seguridad informática.

## Alcance del Proyecto

### Contenido Permitido

- Apuntes y resúmenes de conceptos teóricos.
- Configuraciones de laboratorios virtuales (VirtualBox, VMware, Docker, etc.).
- Writeups de CTFs públicos y desafíos educativos.
- Guías de uso de herramientas de seguridad en entornos controlados.
- Buenas prácticas de hardening y defensa.
- Recursos oficiales: certificaciones, documentación técnica, enlaces educativos.

### Contenido NO Permitido

- Exploits contra sistemas reales o en producción.
- Datos personales, credenciales, IPs o información sensible de terceros.
- Contenido ilegal, malware funcional o herramientas con fines delictivos.
- Material que promueva actividades ilegales o no éticas.
- Ataques, acoso o discriminación entre miembros de la comunidad.

Para más detalles, consulta el archivo [RULES.md](RULES.md).

## Cómo Contribuir

Valoramos y agradecemos todas las contribuciones de la comunidad. Para contribuir:

1. Lee el archivo [CONTRIBUTING.md](CONTRIBUTING.md) para conocer el proceso completo.
2. Familiarízate con las [RULES.md](RULES.md) del repositorio.
3. Crea un fork del repositorio.
4. Realiza tus cambios en una nueva rama.
5. Envía un Pull Request con una descripción clara.

Todas las contribuciones serán revisadas por los mantenedores antes de ser aceptadas.

## Advertencias Importantes

### Uso Exclusivamente Educativo

Este repositorio es **únicamente con fines educativos**. Todo el contenido debe ser utilizado de manera responsable y ética.

### Legalidad y Ética

- **NO se permite** compartir ni promover actividades ilegales.
- Cualquier técnica ofensiva debe estar orientada exclusivamente a **laboratorios de prueba y entornos controlados**.
- **NUNCA** se debe aplicar ningún contenido de este repositorio contra sistemas reales sin autorización explícita y por escrito.
- El incumplimiento de estas normas puede tener consecuencias legales graves.

### Responsabilidad del Usuario

Cada usuario es responsable del uso que haga del contenido de este repositorio. Los mantenedores y colaboradores no se hacen responsables del mal uso de la información aquí compartida.
