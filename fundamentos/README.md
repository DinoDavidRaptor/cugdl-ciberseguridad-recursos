# Fundamentos de Ciberseguridad

Esta carpeta contiene apuntes, resúmenes y recursos sobre los conceptos fundamentales de ciberseguridad organizados por área temática.

---

## Contenido

### Redes
Conceptos básicos de redes, protocolos, arquitecturas y seguridad en redes.

**Temas incluidos:**
- Modelo OSI y TCP/IP
- Protocolos de red (HTTP, HTTPS, DNS, FTP, SSH, etc.)
- Seguridad en redes (VPN, Firewalls, IDS/IPS)
- Análisis de tráfico de red
- Configuración segura de redes

### Sistemas Operativos
Fundamentos de sistemas operativos con enfoque en seguridad.

**Temas incluidos:**
- Linux: Comandos básicos, permisos, administración
- Windows: PowerShell, Active Directory, políticas de grupo
- Hardening de sistemas operativos
- Gestión de usuarios y permisos
- Logs y auditoría de sistemas

### Criptografía
Conceptos de criptografía aplicada a la ciberseguridad.

**Temas incluidos:**
- Criptografía simétrica y asimétrica
- Funciones hash
- Certificados digitales y PKI
- SSL/TLS
- Cifrado de discos y archivos
- Algoritmos criptográficos comunes

### Programación
Conceptos de programación aplicados a ciberseguridad.

**Temas incluidos:**
- Python para seguridad
- Bash scripting
- PowerShell scripting
- Expresiones regulares
- Automatización de tareas de seguridad
- Análisis de código seguro

---

## Cómo Contribuir

Si deseas agregar contenido a esta sección:

1. Crea un archivo `.md` con un nombre descriptivo
2. Sigue la plantilla de apuntes disponible en `/plantillas/plantilla-apuntes.md`
3. Coloca el archivo en la subcarpeta correspondiente
4. Incluye referencias y fuentes al final del documento
5. Envía un Pull Request siguiendo la guía de [CONTRIBUTING.md](../CONTRIBUTING.md)

---

## Estructura Recomendada

Cada subcarpeta puede contener:

```
subcarpeta/
├── README.md           # Descripción del contenido de la subcarpeta
├── tema-1.md           # Apunte sobre un tema específico
├── tema-2.md
├── img/                # Imágenes y diagramas
│   └── diagrama-1.png
└── recursos.md         # Enlaces y recursos adicionales
```
