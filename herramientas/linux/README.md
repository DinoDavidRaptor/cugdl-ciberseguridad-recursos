# Herramientas para Linux

Guías de herramientas de ciberseguridad para sistemas Linux.

---

## Categorías

### Análisis de Red
- Wireshark
- tcpdump
- Nmap
- Netcat
- Masscan
- Ettercap

### Análisis Forense
- Autopsy
- Sleuth Kit
- Volatility
- Foremost
- Binwalk

### Pentesting
- Metasploit Framework
- Burp Suite
- SQLmap
- Aircrack-ng
- John the Ripper
- Hydra

### Hardening
- Lynis
- AIDE
- Fail2ban
- SELinux/AppArmor
- ClamAV

### Monitoreo
- Snort
- Suricata
- OSSEC
- Nagios
- Zabbix

---

## Advertencia

Estas herramientas deben usarse SOLO en:
- Sistemas propios
- Laboratorios de práctica
- Sistemas con autorización explícita por escrito
