# Herramientas para Windows

Guías de herramientas de ciberseguridad para sistemas Windows.

---

## Categorías

### Análisis de Red
- Wireshark
- Network Miner
- Microsoft Network Monitor
- Fiddler

### Análisis Forense
- FTK Imager
- Autopsy
- Volatility
- X-Ways Forensics
- Redline

### Pentesting
- PowerShell Empire (contexto educativo)
- Covenant
- BloodHound (AD enumeration)
- Mimikatz (perspectiva defensiva)
- Responder

### Hardening
- Windows Defender
- AppLocker
- GPO (Group Policy Objects)
- EMET
- Microsoft Baseline Security Analyzer

### Monitoreo
- Sysmon
- Event Viewer
- Windows Event Forwarding
- PowerShell logging
- Process Monitor

---

## Advertencia

Estas herramientas deben usarse SOLO en:
- Sistemas propios
- Laboratorios de práctica
- Sistemas con autorización explícita por escrito
