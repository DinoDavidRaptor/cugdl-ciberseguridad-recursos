# Herramientas de Ciberseguridad

Esta carpeta contiene guías de uso responsable de herramientas de ciberseguridad organizadas por plataforma.

---

## Contenido

### Linux
Herramientas de seguridad para sistemas Linux.

**Categorías:**
- Análisis de red (Wireshark, tcpdump, Nmap)
- Análisis forense (Autopsy, Sleuth Kit)
- Pentesting (Metasploit, Burp Suite, SQLmap)
- Hardening (Lynis, AIDE, Fail2ban)
- Monitoreo (Snort, Suricata, OSSEC)

### Windows
Herramientas de seguridad para sistemas Windows.

**Categorías:**
- Análisis de red (Wireshark, Network Miner)
- Análisis forense (FTK Imager, Volatility, Autopsy)
- Pentesting (PowerShell Empire, Covenant, Mimikatz en contexto defensivo)
- Hardening (Windows Defender, AppLocker, GPO)
- Monitoreo (Sysmon, Event Viewer, WEFFLES)

### Multiplataforma
Herramientas que funcionan en múltiples sistemas operativos.

**Categorías:**
- Análisis de vulnerabilidades (Nessus, OpenVAS, Nikto)
- Análisis web (Burp Suite, OWASP ZAP, Postman)
- Criptografía (OpenSSL, GPG, VeraCrypt)
- Gestión de contraseñas (KeePass, Bitwarden)
- SIEM (Splunk, ELK Stack, Wazuh)

---

## Advertencia Importante

**Todas las herramientas deben usarse de forma responsable y ética:**

- Solo en sistemas propios o con autorización explícita por escrito
- En entornos de laboratorio controlados
- Cumpliendo con las leyes locales e internacionales
- Siguiendo códigos de ética profesional

El uso indebido de estas herramientas es ILEGAL y puede tener consecuencias legales graves.

---

## Formato de Guías

Cada guía de herramienta debe incluir:

1. **Descripción**: Qué es la herramienta y para qué sirve
2. **Instalación**: Cómo instalar en diferentes plataformas
3. **Uso básico**: Comandos y opciones fundamentales
4. **Ejemplos prácticos**: Casos de uso en entornos controlados
5. **Buenas prácticas**: Uso responsable y ético
6. **Advertencias legales**: Recordatorio sobre autorización
7. **Referencias**: Documentación oficial y recursos adicionales

---

## Cómo Contribuir

Si deseas agregar una guía de herramienta:

1. Verifica que la herramienta sea legítima y de uso legal
2. Crea un archivo `.md` con el nombre de la herramienta
3. Sigue el formato de guías descrito arriba
4. Incluye SIEMPRE advertencias sobre uso responsable
5. Coloca el archivo en la carpeta correspondiente (linux/windows/multiplataforma)
6. Envía un Pull Request siguiendo [CONTRIBUTING.md](../CONTRIBUTING.md)
