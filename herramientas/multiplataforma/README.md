# Herramientas Multiplataforma

Guías de herramientas de ciberseguridad que funcionan en múltiples sistemas operativos.

---

## Categorías

### Análisis de Vulnerabilidades
- Nessus
- OpenVAS
- Nikto
- OWASP Dependency-Check
- Trivy

### Análisis Web
- Burp Suite
- OWASP ZAP
- Postman
- Insomnia
- Nuclei

### Criptografía
- OpenSSL
- GPG/PGP
- VeraCrypt
- HashCat
- CyberChef

### Gestión de Contraseñas
- KeePass
- Bitwarden
- 1Password
- LastPass

### SIEM y Logging
- Splunk
- ELK Stack (Elasticsearch, Logstash, Kibana)
- Graylog
- Wazuh

### Desarrollo Seguro
- SonarQube
- GitLeaks
- Bandit
- Snyk

---

## Advertencia

Estas herramientas deben usarse SOLO en:
- Sistemas propios
- Laboratorios de práctica
- Sistemas con autorización explícita por escrito
