# Respuesta a Incidentes

Recursos sobre metodologías y procedimientos de respuesta a incidentes de seguridad.

---

## Temas

### Ciclo de Respuesta a Incidentes
1. Preparación
2. Detección y análisis
3. Contención
4. Erradicación
5. Recuperación
6. Lecciones aprendidas

### Preparación
- Creación de equipos de respuesta (CSIRT)
- Políticas y procedimientos
- Herramientas de respuesta
- Comunicación y escalamiento

### Detección y Análisis
- Identificación de indicadores de compromiso (IoC)
- Análisis de alertas
- Determinación de alcance
- Clasificación de incidentes

### Contención
- Contención a corto plazo
- Contención a largo plazo
- Aislamiento de sistemas comprometidos
- Preservación de evidencia

### Erradicación y Recuperación
- Eliminación de amenazas
- Restauración de sistemas
- Validación de seguridad
- Monitoreo post-incidente

### Documentación
- Plantillas de reporte de incidentes
- Documentación de acciones realizadas
- Reporte ejecutivo
- Reporte técnico

---

## Playbooks

Los playbooks son guías paso a paso para responder a tipos específicos de incidentes:

- Ransomware
- Phishing
- Fuga de datos
- Compromiso de credenciales
- Malware
- DDoS
