# Hardening de Sistemas

Recursos y apuntes sobre fortificación y aseguramiento de sistemas.

---

## Temas

### Hardening de Sistemas Operativos
- Hardening de Linux (CentOS, Ubuntu, Debian)
- Hardening de Windows Server
- Hardening de macOS
- Desactivación de servicios innecesarios
- Configuración segura de permisos

### Hardening de Servicios
- Hardening de servidores web (Apache, Nginx, IIS)
- Hardening de bases de datos (MySQL, PostgreSQL, MongoDB)
- Hardening de SSH
- Hardening de FTP/SFTP
- Hardening de servicios de correo

### Buenas Prácticas
- Principio de mínimo privilegio
- Autenticación multifactor (MFA)
- Actualizaciones y parches
- Configuración de firewalls
- Auditoría y monitoreo

### Benchmarks y Estándares
- CIS Benchmarks
- STIG (Security Technical Implementation Guides)
- NIST Guidelines
