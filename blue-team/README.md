# Blue Team

Esta carpeta contiene recursos, apuntes y guías sobre defensa en ciberseguridad, orientados a la detección, prevención y respuesta a incidentes.

---

## Contenido

### Análisis Forense
Técnicas y herramientas para análisis forense digital.

**Temas incluidos:**
- Análisis forense de discos
- Análisis forense de memoria RAM
- Análisis forense de red
- Cadena de custodia
- Herramientas: Autopsy, Volatility, FTK Imager
- Preservación de evidencia digital

### Hardening
Fortificación y aseguramiento de sistemas.

**Temas incluidos:**
- Hardening de Linux
- Hardening de Windows
- Hardening de servidores web
- Hardening de bases de datos
- Configuraciones seguras
- Benchmarks de seguridad (CIS, STIG)

### SIEM
Gestión de eventos e información de seguridad.

**Temas incluidos:**
- Conceptos de SIEM
- Implementación de SIEM
- Análisis de logs
- Correlación de eventos
- Herramientas: Splunk, ELK Stack, Wazuh
- Casos de uso y alertas

### Respuesta a Incidentes
Procedimientos y metodologías para respuesta a incidentes de seguridad.

**Temas incluidos:**
- Ciclo de respuesta a incidentes (NIST)
- Playbooks de respuesta
- Análisis de malware
- Contención y erradicación
- Recuperación post-incidente
- Documentación de incidentes

---

## Enfoque

Todo el contenido de esta sección está orientado a la **defensa** y **protección** de sistemas, así como a la **detección temprana** y **respuesta efectiva** ante amenazas de seguridad.

---

## Cómo Contribuir

Si deseas agregar contenido a esta sección:

1. Crea un archivo `.md` con un nombre descriptivo
2. Sigue la plantilla de apuntes disponible en `/plantillas/plantilla-apuntes.md`
3. Coloca el archivo en la subcarpeta correspondiente
4. Incluye ejemplos prácticos cuando sea posible
5. Incluye referencias y fuentes al final del documento
6. Envía un Pull Request siguiendo la guía de [CONTRIBUTING.md](../CONTRIBUTING.md)
