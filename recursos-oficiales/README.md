# Recursos Oficiales

Esta carpeta contiene enlaces y referencias a recursos oficiales, certificaciones, documentación técnica y material educativo de ciberseguridad.

---

## Contenido

### Certificaciones
Información sobre certificaciones reconocidas en ciberseguridad.

**Certificaciones incluidas:**
- **Entry Level**: Security+, CEH, GIAC GSEC
- **Intermediate**: OSCP, GCIA, GCIH, CySA+
- **Advanced**: OSEP, OSCE, GXPN, CISSP
- **Especialidades**: GCFA, GCFE, GPEN, GWAPT

### Documentación Técnica
Enlaces a documentación oficial y técnica.

**Recursos incluidos:**
- Documentación de protocolos (RFCs)
- Guías de NIST
- Estándares ISO/IEC
- Documentación de OWASP
- Frameworks de seguridad (MITRE ATT&CK, CIS Controls)
- Manuales oficiales de herramientas

### Enlaces Útiles
Colección de recursos educativos, comunidades y plataformas.

**Recursos incluidos:**
- Plataformas de aprendizaje (HackTheBox, TryHackMe, etc.)
- Blogs de seguridad reconocidos
- Podcasts de ciberseguridad
- Canales de YouTube educativos
- Comunidades y foros
- Repositorios de GitHub relevantes

---

## Propósito

Esta sección tiene como objetivo centralizar enlaces a recursos de calidad, oficiales y reconocidos en la industria de la ciberseguridad, facilitando el aprendizaje y desarrollo profesional.

---

## Cómo Contribuir

Si deseas agregar recursos:

1. Verifica que el recurso sea:
   - Oficial o ampliamente reconocido
   - De acceso público o gratuito (o indicar si es de pago)
   - Relevante para la comunidad educativa
   - Actualizado y mantenido

2. Organiza el recurso en la categoría correspondiente

3. Incluye:
   - Nombre del recurso
   - URL
   - Breve descripción
   - Idioma disponible
   - Si es gratuito o de pago

4. Envía un Pull Request siguiendo [CONTRIBUTING.md](../CONTRIBUTING.md)

---

## Estructura Recomendada

Cada subcarpeta puede contener:

```
subcarpeta/
├── README.md              # Descripción de la categoría
├── recursos-gratuitos.md  # Recursos gratuitos
├── recursos-pago.md       # Recursos de pago
└── comparativas.md        # Comparativas (si aplica)
```
