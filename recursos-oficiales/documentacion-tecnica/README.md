## Frameworks y Metodologías

### MITRE ATT&CK
- **Descripción**: Framework de tácticas y técnicas adversarias
- **URL**: [https://attack.mitre.org/](https://attack.mitre.org/)
- **Idioma**: Inglés
- **Uso**: Threat intelligence, detección, respuesta a incidentes

### NIST Cybersecurity Framework
- **Descripción**: Framework para gestión de riesgos de ciberseguridad
- **URL**: [https://www.nist.gov/cyberframework](https://www.nist.gov/cyberframework)
- **Idioma**: Inglés
- **Uso**: Gestión de seguridad organizacional

### CIS Controls
- **Descripción**: Controles de seguridad prioritarios
- **URL**: [https://www.cisecurity.org/controls](https://www.cisecurity.org/controls)
- **Idioma**: Inglés
- **Uso**: Hardening, aseguramiento de sistemas

- **Tipo**: Estándar internacional

### PCI DSS
- **Descripción**: Seguridad de datos de tarjetas de pago
- **URL**: [https://www.pcisecuritystandards.org/](https://www.pcisecuritystandards.org/)
- **Uso**: Cumplimiento normativo

### GDPR (Reglamento General de Protección de Datos)
