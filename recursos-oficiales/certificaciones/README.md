# Certificaciones de Ciberseguridad

Información sobre certificaciones reconocidas en la industria de la ciberseguridad.

---

## Certificaciones por Nivel

### Entry Level (Principiantes)

#### CompTIA Security+
- **Proveedor**: CompTIA
- **Nivel**: Entrada
- **Enfoque**: Fundamentos de seguridad
- **Costo**: Aproximado $381 USD
- **Vigencia**: 3 años
- **Sitio oficial**: [https://www.comptia.org/certifications/security](https://www.comptia.org/certifications/security)

#### CEH (Certified Ethical Hacker)
- **Proveedor**: EC-Council
- **Nivel**: Entrada/Intermedio
- **Enfoque**: Hacking ético
- **Costo**: Aproximado $1,199 USD
- **Sitio oficial**: [https://www.eccouncil.org/programs/certified-ethical-hacker-ceh/](https://www.eccouncil.org/programs/certified-ethical-hacker-ceh/)

### Intermediate Level (Intermedio)

#### OSCP (Offensive Security Certified Professional)
- **Proveedor**: Offensive Security
- **Nivel**: Intermedio
- **Enfoque**: Pentesting práctico
- **Costo**: Desde $999 USD
- **Formato**: Examen práctico de 24 horas
- **Sitio oficial**: [https://www.offensive-security.com/pwk-oscp/](https://www.offensive-security.com/pwk-oscp/)

#### CySA+ (Cybersecurity Analyst)
- **Proveedor**: CompTIA
- **Nivel**: Intermedio
- **Enfoque**: Análisis de ciberseguridad
- **Costo**: Aproximado $392 USD
- **Sitio oficial**: [https://www.comptia.org/certifications/cybersecurity-analyst](https://www.comptia.org/certifications/cybersecurity-analyst)

#### GCIA (GIAC Certified Intrusion Analyst)
- **Proveedor**: SANS/GIAC
- **Nivel**: Intermedio
- **Enfoque**: Detección de intrusiones
- **Sitio oficial**: [https://www.giac.org/certifications/certified-intrusion-analyst-gcia/](https://www.giac.org/certifications/certified-intrusion-analyst-gcia/)

### Advanced Level (Avanzado)

#### CISSP (Certified Information Systems Security Professional)
- **Proveedor**: (ISC)²
- **Nivel**: Avanzado
- **Enfoque**: Gestión de seguridad
- **Requisito**: 5 años de experiencia
- **Sitio oficial**: [https://www.isc2.org/Certifications/CISSP](https://www.isc2.org/Certifications/CISSP)

#### OSEP (Offensive Security Experienced Penetration Tester)
- **Proveedor**: Offensive Security
- **Nivel**: Avanzado
- **Enfoque**: Pentesting avanzado
- **Sitio oficial**: [https://www.offensive-security.com/pen300-osep/](https://www.offensive-security.com/pen300-osep/)

#### OSCE (Offensive Security Certified Expert)
- **Proveedor**: Offensive Security
- **Nivel**: Experto
- **Enfoque**: Explotación avanzada
- **Estado**: Reemplazada por OSED, OSEP, OSWE
- **Sitio oficial**: [https://www.offensive-security.com/](https://www.offensive-security.com/)

### Especialidades

#### Forense Digital
- **GCFA** (GIAC Certified Forensic Analyst)
- **GCFE** (GIAC Certified Forensic Examiner)
- **EnCE** (EnCase Certified Examiner)

#### Pentesting Web
- **GWAPT** (GIAC Web Application Penetration Tester)
- **OSWE** (Offensive Security Web Expert)
- **eWPT** (eLearnSecurity Web Application Penetration Tester)

#### Cloud Security
- **CCSP** (Certified Cloud Security Professional)
- **AWS Certified Security - Specialty**
- **Google Cloud Professional Cloud Security Engineer**
