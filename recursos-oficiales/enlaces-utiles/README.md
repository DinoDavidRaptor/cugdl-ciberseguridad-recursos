## Plataformas de Aprendizaje

### Práctica Hands-On

#### HackTheBox
- **URL**: [https://www.hackthebox.com/](https://www.hackthebox.com/)
- **Tipo**: Máquinas virtuales vulnerables, CTFs
- **Costo**: Freemium
- **Nivel**: Todos

#### TryHackMe
- **URL**: [https://tryhackme.com/](https://tryhackme.com/)
- **Tipo**: Rutas de aprendizaje guiadas
- **Costo**: Freemium
- **Nivel**: Principiante a Avanzado

#### PicoCTF
- **URL**: [https://picoctf.org/](https://picoctf.org/)
- **Tipo**: CTF educativo
- **Costo**: Gratuito
- **Nivel**: Principiante a Intermedio

#### OverTheWire
- **URL**: [https://overthewire.org/](https://overthewire.org/)
- **Tipo**: Wargames de seguridad
- **Costo**: Gratuito
- **Nivel**: Todos

#### VulnHub
- **URL**: [https://www.vulnhub.com/](https://www.vulnhub.com/)
- **Tipo**: Máquinas virtuales descargables
- **Costo**: Gratuito
- **Nivel**: Todos
