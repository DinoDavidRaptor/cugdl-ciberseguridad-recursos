# CTF (Capture The Flag)

Recursos relacionados con competencias y desafíos CTF.

---

## Subcarpetas

- **writeups/**: Soluciones detalladas de CTFs públicos
- **desafios/**: Desafíos de práctica creados por la comunidad

---

## Writeups

Los writeups deben:
- Ser de CTFs públicos y completados
- Incluir descripción del desafío
- Explicar el proceso de resolución paso a paso
- Incluir comandos y código utilizado
- Contener capturas de pantalla relevantes
- Mencionar lecciones aprendidas
- Usar la plantilla `/plantillas/plantilla-writeup.md`

---

## Plataformas CTF Populares

- [HackTheBox](https://www.hackthebox.com/)
- [TryHackMe](https://tryhackme.com/)
- [PicoCTF](https://picoctf.org/)
- [CTFtime](https://ctftime.org/)
- [OverTheWire](https://overthewire.org/)
- [Root-Me](https://www.root-me.org/)

---

## Categorías Comunes de CTF

- **Web**: Vulnerabilidades web (SQL injection, XSS, etc.)
- **Pwn**: Binary exploitation, buffer overflow
- **Crypto**: Criptografía y criptoanálisis
- **Forense**: Análisis forense digital
- **Reversing**: Ingeniería inversa
- **OSINT**: Open Source Intelligence
- **Misc**: Categoría miscelánea
