# Writeups de CTF

Soluciones detalladas de desafíos CTF públicos con fines educativos.

---

## Formato de Writeups

Usa la plantilla `/plantillas/plantilla-writeup.md` para mantener consistencia.

### Estructura Recomendada

1. Título del desafío
2. Plataforma y categoría
3. Nivel de dificultad
4. Descripción del desafío
5. Proceso de resolución (paso a paso)
6. Solución y flag
7. Lecciones aprendidas
8. Referencias

---

## Organización

Organiza los writeups por plataforma o por categoría:

```
writeups/
├── hackthebox/
├── tryhackme/
├── picoctf/
└── otros/
```

o

```
writeups/
├── web/
├── crypto/
├── pwn/
├── forense/
└── reversing/
```

---

## Buenas Prácticas

- Solo escribir writeups de CTFs completados y públicos
- Respetar las políticas de las plataformas (no publicar writeups de máquinas activas)
- Explicar el razonamiento, no solo los comandos
- Incluir capturas de pantalla relevantes
- Anonimizar cualquier información sensible
- Dar crédito a los creadores del desafío
