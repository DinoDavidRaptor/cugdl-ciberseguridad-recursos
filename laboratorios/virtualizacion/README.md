# Virtualización

Guías para configurar entornos virtualizados de práctica para ciberseguridad.

---

## Subcarpetas

- **virtualbox/**: Guías de VirtualBox
- **vmware/**: Guías de VMware Workstation/Player
- **docker/**: Contenedores Docker para laboratorios

---

## Temas Generales

- Instalación de hipervisores
- Configuración de redes virtuales
- Creación de laboratorios aislados
- Gestión de máquinas virtuales
- Snapshots y clonación
- Optimización de rendimiento
- Resolución de problemas comunes

---

## Advertencia

Los entornos virtualizados para seguridad deben:
- Estar aislados de la red de producción
- Usar redes internas o NAT según sea necesario
- Tener snapshots antes de pruebas destructivas
- No contener datos reales o sensibles
